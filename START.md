# Start here

Bring your idea. Your AI helps you explore it and looks after the project files.

1. Give your AI access to this repository and point it to `START.md`.
2. Describe your idea in the conversation. Rough thoughts, questions and contradictions are welcome; you do not need to edit a file or choose a technical setup.
3. Explore together. When you want to keep the project for future sessions, ask the AI to retain it. The AI prepares the memory for your review; further exploration can still be the next step.

If your AI cannot read the repository, give it this file first. It should tell you which additional files it needs. If it cannot edit files, it should explain that limitation and provide the prepared content without claiming it saved anything.

## For the AI

- This is the shared entry point, regardless of tool. Read `memory/agreements.md` and follow **Starting and evolving a project**. Inspect repository and Git state before repository-dependent claims or changes; disclose unavailable access.
- Read `memory/now.md` when present, and `memory/intent.md` when present and purpose or scope matters. Follow only pointers relevant to the task. Preserve existing approved memory, including partially initialised projects.
- If no real project memory exists, use the owner's idea from the conversation and any existing idea notes. If neither supplies an idea, ask for it. Reflect your understanding and help with the requested exploration; do not require the owner to fill in a template or initialise from placeholder text.
- When asked to retain or initialise the project, follow the [initialisation procedure](README.md#initialisation-procedure). Prepare and edit the files yourself where access permits. Do not initialise or implement merely because an idea is detailed; maintenance of this foundation is not a request to initialise a new project.
- The owner may be using any AI. Ask only for missing information needed by the next step, and request access or specific files only when required. Be explicit about read-only or chat-only limitations; never claim unsaved content is in the repository.
